# Результаты для жюри

- `dev/results.json` — 65 исходных DEV-диалогов: 60 чатов и 5 звонков.
- `prod/results.json` — 10 настоящих контрольных чатов после их получения.

Схема: Results JSON 1.0. Команда: **Fantastic Four**.

Файл включает все ID, в том числе ошибки. `status: "error"` означает отсутствие допустимой полной AI-оценки, а не нулевой балл. Наличие валидного JSON не означает, что все разговоры оценены или что оценки совпадают с эталоном.

Повторная генерация и независимая проверка описаны в [руководстве по сдаче](../docs/SUBMISSION.md). Контрольный файл не подменяется пустым шаблоном до получения настоящих данных.
