# Freedom CQA Studio материалы для жюри

**Участник: Бибол Жайлыбаев. Команда: Fantastic Four. Версия приложения: 0.7.0. Дата: 8 ноября 2026.**

Репозиторий участника: [Bibol06/CQA-Studio-](https://github.com/Bibol06/CQA-Studio-).

Freedom CQA Studio — локальный прототип оценки качества поддержки. Он применяет изменяемый чек-лист к диалогу, показывает основания оценки, рассчитывает итог и сохраняет пересмотр. Дополнительные модули анализируют темы и сами записи звонков. Проект реализован с помощью AI-ассистента; используется готовая модель, собственная нейросеть не обучалась.

## Подтверждённое состояние

Обработано 65 DEV-диалогов: 60 чатов и 5 звонков, 35 RU, 15 KZ, 15 EN. Для всех сохранены восемь оценок текущего чек-листа. Официальный файл содержит 65 записей ok и 0 error; это полнота обработки, не точность модели. Отдельное распознавание до и после DSP выполнено для пяти звонков: 86 пар фрагментов Whisper и 10 запросов Gemini в успешных запусках.

Полный набор программных проверок последней функциональной версии: **141 Python и 18 JavaScript**. Свежие журналы текущей проверки включены в `evidence`. Дополнительно проверены распаковка архива, целостность файлов, повторный запуск подготовки демонстрации и отдельный сервер с тремя синтетическими чатами без ключа. Тесты формата, цитат и расчёта не заменяют независимую проверку смысловой правильности AI.

Ранний пилот: 45 совпадений из 48 оценок на шести диалогах относительно предварительной разметки ассистента. Независимых человеческих оценщиков в этом сравнении нет. Это не заявленная точность на скрытом контроле. Отчёт друга 65/72 к этому проекту не относится.

## Обязательные условия сдачи

Код, README и результаты должны быть доступны в открытом Git-репозитории до стоп-кода, по правилам Student Guide и Results Appendix. **Подготовленная папка или архив сами по себе не означают commit, push или отправку организаторам.**

В этой версии есть DEV-файл. Контрольный `results/prod/results.json` отсутствует: в локальных данных нет отдельной группы из десяти контрольных чатов. DEV не подменяет контроль. После получения контроля следует импортировать настоящую группу, оценить её, выполнить экспорт и проверку по [SUBMISSION.md](../docs/SUBMISSION.md).

В архиве нет ключей, локальной SQLite, подписанных аудиоссылок или исходных разговоров. Для самостоятельного просмотра интерфейса добавлены три явно синтетических чата. В демонстрации без ключа работает ограниченный режим правил, без вымышленных AI-оценок. Для воспроизведения результатов нужны официальные входные данные и доступ к модели.
