# Источники и границы публикации

Официальные требования прочитаны из файлов организаторов:

- `CQA_Hackathon_Student_Guide_v3 1_261107_123938.pdf`, 4 страницы: функции, данные, интерфейс, защита и Git.
- `CQA_Student_Guide_Appendix_Results.pdf`, 3 страницы: Results JSON 1.0 и десять контрольных чатов.
- `CQA_Chat_Quality_Checklist 1 (2).pdf`: исходный чек-лист; конфигурация и арифметика реализованы в `cqa/domain.py`.

Документы организаторов не перепубликуются в архиве. Секретная ссылка их API не включена.

Для понимания структуры поставки рассмотрены присланный `CQA-Analytics-Team.rar` и [репозиторий товарища](https://github.com/sejtzanoverasyl-arch/CQA-Analytics). Они использованы как пример комплектации. Исходный код, авторство, предварительная разметка и показатели другого решения в Freedom CQA Studio не переносятся.

Собственные источники: код текущего проекта, локальная SQLite, исходные DEV-данные для сопоставления ID, результаты тестов и исторические отчёты в `docs/`. В `jury/evidence` вынесены агрегаты, ID, счётчики и предварительные оценки без полных транскриптов.

Программная проверка подтверждает структуру и арифметику. Без независимой разметки она не подтверждает точность модели. Ранее полученные показатели сохраняют название модели, размер выборки и источник разметки.

Публичная поставка не содержит ключей, `.env`, базы SQLite, модельных файлов, подписанных ссылок на записи, оригинальных разговоров, журналов браузера или содержания чужого архива. В неё входит официальный файл результатов, предназначенный организаторами для Git. Синтетические примеры помечены отдельно.
