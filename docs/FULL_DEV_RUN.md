# Полная проверка DEV

Запуск начат 7 ноября 2026 по просьбе оценить весь набор: 60 чатов и 5 звонков на RU, KZ и EN. Используется настроенный Gemini API. Исходные транскрипты и прежние оценки сохраняются.

## Итог

Проверка завершена 7 ноября 2026. **65 из 65** диалогов имеют полную исходную AI-оценку текущего чек-листа v2: RU 35/35, KZ 15/15, EN 15/15; чаты 60/60 и звонки 5/5. Это 520 ответов по критериям, включая разрешённые N/A. Оценки звонков получены по транскриптам; аудио не анализировалось.

В `results/dev/results.json` сохранены 65 записей `status=ok`, ошибок обработки 0. Независимая программная проверка ID, типов, доказательств и арифметики файла прошла. Это проверка формата и расчёта, а не точности относительно эталона жюри. Файл сохранён локально.

Неполные дополнительные блоки не подменяются выдуманным содержимым. При 65 готовых оценках не у всех диалогов есть резюме или список вопросов. Флаги и нарушения — выводы модели, требующие проверки.

## Что этот запуск делает

Для каждого диалога модель получает текст и актуальный чек-лист, затем возвращает оценки. Программа проверяет допустимые значения, индексы и точность цитат, вычисляет балл и сохраняет историю. Отдельно проверяются резюме, рекомендации и разбор вопросов.

Приложение **не запускает обучение модели** и не обновляет её веса. Результаты автоматической оценки не являются эталонной разметкой. Улучшение инструкций по DEV — настройка нашего оценщика. Независимая проверка на новых данных нужна отдельно; официальный контроль организаторов не используется для настройки.

## Версия правил

Сохранена версия чек-листа **v2**: уточнены условия N/A для К2, составная формула К7 и необходимость учитывать все самостоятельные вопросы клиента, в том числе поздние. Восемь критериев, веса, допустимые шкалы и арифметика сохранены. Полный снимок: `research/checklist_clarified_v2.json`.

Это уточнение текста правил и инструкций, а не обучение на эталонных ответах. Оценки прежней версии не подменяют новую проверку.

## Надёжность и повторные запросы

В первом проходе все 65 диалогов отправлены на оценку. По v2 сохранено 48 полных результатов; 17 диалогам требуется повтор. Всего в этом проходе 66 попыток: один неудачный пилот повторно включён в основную очередь. Причины отказов: невалидный JSON, неточная цитата, недопустимая ступень, HTTP 503 и HTTP 429. Недопустимые ответы не округляются и не заменяются удобными значениями.

Каждая попытка сохраняется в журнале, включая неудачи. Стоимость неизвестна, пока не заданы цены; неизвестный расход не равен нулю. Повторы после квоты выполняются только после проверки состояния и задержки.

После паузы один короткий повтор подтвердил восстановление доступа. Чаты повторно обработаны с прежними строгими проверками. У последних двух звонков сохранялись неточные цитаты. Gemini 3.8 дала HTTP 503 и тайм-аут; high у Flash Lite также не устранил неточность перепечатки. Эти неудачные попытки сохранены в журнале.

Для завершения введён `source-turns-v4`: модель выбирает номера реплик, сервер проверяет их границы и копирует исходный текст. Явно переданная неверная цитата по-прежнему отклоняется; неизвестные индексы, bool вместо номера и неправильные диапазоны также отклоняются. Смысловую верность выбора реплики этот метод не доказывает. Два повторных запроса после обновления завершились успешно. 63 прежние оценки сохраняют старый способ проверки, две последние используют `source-turns-v4`; чек-лист у всех v2.

Прошли 100 Python-тестов и 5 JavaScript-тестов, в том числе проверка копирования точного источника, отклонения неизвестного индекса и сохранения строгого валидатора официального файла.

## Проверка смысла

В дополнительном русском пилоте v2 исправлена оценка К7 и появились поздние вопросы. Это знакомый пример для настройки, а не независимая проверка качества.

При чтении нового KZ-примера `p1-kz-001` ассистент обнаружил, что модель приняла «Оқасы жоқ» за предложение дальнейшей помощи. В `p1-ru-002` разбор отдельных вопросов пропустил вопрос о необходимости отправки отчёта. Поэтому полнота списка вопросов и верность оценки не следуют из успешной проверки JSON и цитат. Для проверки казахского языка желателен независимый носитель.

По К7 в `p1-kz-001` открыта одна апелляция с предварительной заметкой ассистента. Она не рассмотрена человеком; исходная оценка модели не изменена. Для дальнейшей настройки сначала проверить спорные ответы и собрать независимые эталоны. Ни один процент покрытия из этой сводки не является точностью AI.

## Как воспроизвести сводку

```powershell
python -X utf8 research/full_dev_report.py
```

Сводка сохраняется в игнорируемый `data/full_dev_report.json`. В ней только числа, ID и параметры обработки; полные транскрипты и ключи не выгружаются. Поля `evaluated`, `summaries` и `request_analysis` имеют разные значения: наличие балла не гарантирует наличие всех дополнительных блоков. Числа нарушений относятся к исходным AI-ответам и не являются измерением точности или частоты проблем в реальном потоке клиентов.
