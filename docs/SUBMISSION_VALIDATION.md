# Проверка официального экспорта — 7 ноября 2026

Версия приложения: 0.4.0. Источник схемы: официальное дополнение Results JSON 1.0, все три страницы прочитаны и просмотрены после рендеринга.

## Результат

- Команда: **Fantastic Four**.
- Сформирован `results/dev/results.json`: **65 исходных ID**, **7 ok**, **58 error**, все 60 чатов и 5 звонков учтены.
- Полная оценка после ручной апелляции не подменяет исходную AI-оценку в файле жюри.
- Текущая локальная база содержит результаты, полученные и после исходного эксперимента обновления; исторические отчёты `VALIDATION.md` и `UPDATE_VALIDATION.md` не пересчитывались.
- В настоящий контроль данные ещё не загружены; `results/prod/results.json` не создан. Проверка контроля выполнена на отдельном временном наборе и не выдана за результат организаторов.
- Публичный remote не настроен. Код и DEV-файл подготовлены локально; отправка организаторам не выполнена.

## Автоматические проверки

**76 Python-тестов и 3 JavaScript-теста проходят.** Новые проверки покрывают:

- Ровно 65 DEV-записей с составом 60/5 и ровно 10 контрольных чатов.
- Сохранение всех ID, включая неуспешно оценённые; запрет пропусков и дубликатов.
- Преобразование Да/Нет в JSON boolean, разрешённого N/A в null; различение boolean и числа.
- Коды критериев, допустимые ступени, доказательства по исходной нумерации, раскрытие диапазонов реплик.
- Пример из PDF: N/A у discovery/identification, consultation=15, dialogue=7 дают **85.38**.
- Независимый critical_flag без обнуления итога; запрет неверного итога и несогласованного флага.
- Явный error для отсутствующей, устаревшей или частичной проверки; запрет выдавать режим правил за LLM.
- Защиту от несовместимых весов и чек-листов; ожидание завершения активных заданий.
- Сохранение исходного результата после апелляции, фактические имена использованных моделей.
- Проверку стороннего JSON: неизвестные поля, дубли ключей, NaN/Infinity, неверные типы и выход за границы транскрипта.
- Атомарную запись UTF-8 и резервную копию; недопустимый документ не заменяет прежний файл.
- HTTP-предпросмотр без записи и сохранение по фиксированному пути.
- Гонку интерфейса: запоздавший предпросмотр DEV не появляется после выбора PROD.

## Проверка в браузере и командной строке

Пройдены сценарии: открытие раздела «Сдача жюри», сохранённое название команды, предпросмотр DEV, переключение на ещё не полученный контроль и отказ в выгрузке, сохранение DEV через интерфейс, скачивание копии.

Скачанная копия в папке Downloads разобрана как UTF-8, прошла независимый валидатор и по содержимому совпала с файлом в проекте. Команда `python -X utf8 submission.py check results/dev/results.json --set dev` завершилась успешно. Ошибок JavaScript в проверяемой вкладке не обнаружено.

## Граница результата

**Валидный формат не означает завершённую оценку DEV.** 58 диалогов всё ещё не имеют полной допустимой AI-оценки. После их обработки файл нужно сформировать заново, проверить и отправить в открытый Git-репозиторий. Новых модельных запросов ради проверки экспортера не выполнялось; ключ после перезапуска сервера требуется ввести повторно для дальнейшего анализа.
