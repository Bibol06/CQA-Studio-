# Визуальное оформление Freedom CQA Studio

Интерфейс обновлён по просьбе участника в духе цифровых продуктов Freedom Bank. Референс — [официальный сайт банка](https://bankffin.kz/ru). Это оформление хакатонного Freedom CQA Studio, не официальный банковский продукт. Знак Freedom Bank добавлен по просьбе участника. Точные цвета брендбука не заявляются.

## Что изменилось

Белая боковая панель, зелёные акценты, светлый фон, крупнее основные показатели и заголовки, единые скругления карточек и элементов управления. Тексты диалога и оценки получили более заметную иерархию. Обновлены формы настроек, таблицы аналитики, чек-лист, вкладки звонка и экран сдачи. В боковой панели указаны Fantastic Four и Бибол Жайлыбаев.

Оформление вынесено в `static/freedom-theme.css`, подключённый после базовых стилей. Основные цвета: `#88cf4f` для действия, `#244930` для основной карточки, белый для панелей и `#f5f7f3` для фона. Знак Freedom Bank хранится локально в SVG-контейнере с исходным изображением; геометрический элемент интерфейса создан в SVG. Внешние шрифты и CDN при работе приложения не используются.

На узких экранах меню становится компактным, карточки перестраиваются, а диалог и оценка располагаются последовательно. У навигации есть текстовые подсказки, видимый клавиатурный фокус и режим уменьшенного движения. Глобальное соответствие WCAG отдельно не сертифицировалось.

## Проверка

На локальном приложении проверены ширины 1600, 1024 и 390 пикселей: горизонтального переполнения документа и ошибок JavaScript не обнаружено. Проверены переходы между диалогами, аналитикой, чек-листом, очередью, сдачей и справкой, а также открытие настроек. Автоматические проверки JavaScript пройдены. Проверка выполнялась в отдельном headless-браузере без пользовательского профиля и без новых вызовов AI.

Скриншот `docs/images/demo.png` получен из изолированной базы с тремя синтетическими чатами, работающей в режиме правил. В нём нет оригинальных разговоров организаторов. Частный основной набор, оценки и официальный DEV Results JSON сохранены без изменений.

Исходное изображение не перерисовывалось; показана область щита с сохранением пропорций. Знак и название банка принадлежат правообладателю.
