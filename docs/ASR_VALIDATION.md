- Финальный полный запуск: 141 тест Python и 18 JavaScript прошли. После уточнения изоляции кэша повторно проверены семь ASR-тестов.
- ASR-тесты проверяют неизменность исходного сигнала, конечность DSP и ограничение пика, покрытие записи без разрывов, ошибки RU/KZ в метриках, отсутствие оценки при пустом эталоне, непередачу исходного транскрипта облаку, одинаковый кодек ветвей и отдельное сохранение ASR.
